Como calculamos

Indicadores socioeconômicos vêm do IBGE/INEP/SICONFI; resultados eleitorais vêm dos arquivos abertos do TSE; votos nominais de mandato vêm da API oficial da Câmara. Percentuais de eleição usam como base os votos nominais do cargo. Nenhum valor é estimado: quando não existe, aparece como pendente.
